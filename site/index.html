Brighter.Sharper.

Snaptic's Displays module gives every screen the controls it should have had: brightness and volume for external monitors, sharp HiDPI text, every resolution, color, arrangement, virtual screens and picture in picture.

Your keys, every screen.

Brightness and volume keys drive external monitors over DDC. Below the hardware minimum, Snaptic keeps dimming in software.

2×

Smart HiDPI.

Sharp text at any size on external displays.

Every resolution.

Modes and refresh rates, HiDPI on or off, favorites and undo. New modes ask before they stick.

Picture in picture.

A live copy of any display or window in a floating window, or one display streamed onto another.

Virtual screens.

Displays that exist only in software. Headless, recording, teleprompter.

Arrange, mirror, rotate.

Pick the main display, line screens up, mirror them, rotate one, or turn it off without unplugging it.

Monitor controls.

Contrast, inputs and standby on the monitor itself.

Color.

Gamma, temperature, contrast and invert, per display.

Layouts.

Save a setup and bring it back when those screens connect.

Protection.

Puts your arrangement back when something else changes it.

Extra brightness.

Get Snaptic.It's free.

For any Mac running macOS Sonoma or later.

Download Snaptic.

Version 0.2.0 for Apple silicon and Intel. Unzip it and drag Snaptic to Applications.

Snaptic isn't notarized by Apple yet, so the first time you open it, go to System Settings, Privacy & Security, and click Open Anyway.

Download for Mac

Or build it yourself.

Takes about a minute, and you can read every line first.

  1. Install the tools.

    Apple's free command line tools. Skip this if you have Xcode.

    Terminal
    xcode-select --install

  2. Build it.

    Downloads the source, builds it, and puts Snaptic in Applications.

    Terminal
    git clone https://github.com/revylfitness/snaptic.git
cd snaptic
INSTALL=1 ./scripts/build-app.sh

  3. Say yes.

    Snaptic asks only for what your features need: Accessibility for the switcher and media keys, Screen Recording for thumbnails and picture in picture.

    Terminal
    open /Applications/Snaptic.app
