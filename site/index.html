Get Snaptic.

Build it on your Mac in about a minute. Requires macOS Sonoma or later.

  1. Install the tools.

    Apple's free command line tools. Skip this if you have Xcode.

    xcode-select --install

  2. Build and install.

    Downloads the source, builds it, and puts Snaptic in Applications.

    git clone https://github.com/revylfitness/snaptic.git
cd snaptic
INSTALL=1 ./scripts/build-app.sh

  3. Allow access.

    In System Settings, open Privacy & Security, then turn on Snaptic under Accessibility. Add Screen Recording for thumbnails.

    open /Applications/Snaptic.app

Read the full guide

Snaptic is free, open-source software released under the MIT license. It needs Accessibility access to see its keyboard shortcut and switch windows, and optionally Screen Recording access to show thumbnails. It makes no network connections.
